# Growmatic Compatible eCommerce Theme

This theme is a static HTML/CSS/JavaScript storefront prepared for Growmatic theme import.

## Compatibility
- Public GitHub repository
- Use `main` or `master` as the default branch
- Static frontend assets only
- No PHP, shell scripts, environment files, or server-side code
- Growmatic-compatible eCommerce selectors for products, cart, checkout, variants, search, accounts, wishlist, reviews, coupons, order tracking, contact, newsletter, and WhatsApp ordering

## Supported pages
- `index.html`
- `shop.html`
- `product.html`
- `cart.html`
- `checkout.html`
- `login.html`
- `register.html`
- `contact.html`
- `about.html`
